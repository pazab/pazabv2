# 🧭 PAZAB v2 — 핵심 비즈니스 중심 내비게이션 및 페이지 구성 제안서
> **작성일시**: 2026-06-29 (월) 23:30 KST  
> **목적**: '가입 허들 제거' 및 '근태 자동 관리(HR SaaS) + 대타 SOS' 핵심 비즈니스 루프에 따른 내비게이션 및 페이지 구조 재편

---

## 1. 기존 내비게이션 진단 및 문제점

### 1.1 기존 4대 탭 구조
```
[ 탐색 (/explore) ] ── [ 채팅 (/chat) ] ── [ 성향분석 (/personality) ] ── [ MY (/mypage) ]
```

* **문제점 1 (핵심 가치의 은닉)**: 
  - 파잡 v2의 가장 강력한 락인(Lock-in) 유도 장치이자 사장님이 매일 실행해야 하는 **'자동 근태/급여 관리(SaaS HR)'** 기능이 마이페이지(`MY`) 내부에 깊숙이 숨겨져 있어 접근성이 매우 떨어집니다.
* **문제점 2 (대타 매칭의 고립)**:
  - 긴급 일자리를 매칭하는 **'대타 SOS'** 기능이 메인 탭에 없고 별도 경로(`/daeta`)로 분리되어 있어, 실시간으로 긴급 대타를 조회하거나 호출하기에 동선이 복잡합니다.
* **문제점 3 (성향분석 탭의 저빈도성)**:
  - 성향분석 인터뷰(`HEXACO`)는 서비스 가입 초기 또는 특정 매칭 시점에 집중적으로 사용되는 **'저빈도성 기능'**입니다. 이 기능이 내비게이션 바의 핵심 자리를 차지하는 것은 공간적 낭비입니다.

## 2. 제안: 핵심 가치 중심 5대 탭 구조 (TO-BE)

매일 일어나는 **근태 관리(잔존율)**와 급할 때 사용하는 **대타 SOS(트랜잭션)**를 양대 축으로 설정하는 5대 탭 구조를 제안합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  ① 근태/관리  ──  ② 대타 SOS  ──  ③ 인재/공고  ──  ④ 채팅방  ──  ⑤ 성향/MY   │
│   (/myteam)        (/daeta)       (/explore)      (/chat)      (/mypage)    │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 탭별 세부 역할 및 유저 역할별(점주/알바) 화면 대응

| 탭 이름 | 대표 경로 | 사장님(Employer) 화면 | 알바생(Worker) 화면 | 비즈니스 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **① 근태/관리** | `/myteam` | **점포 직원 현황판**<br>- 직원별 실시간 근태(지각, 출근, 퇴근)<br>- 이번 달 누적 근무시간 & 예상 급여<br>- 신규 직원 초대 코드 발송 | **나의 출퇴근 파트너**<br>- 실시간 GPS 출근/퇴근 패널 (100m 반경)<br>- 캘린더 근무 일지 조회<br>- 월별 급여 명세서(명세서 PDF) 조회 | **리텐션(Retention)**<br>매일 앱에 접속해야 하는 단독 가치(SaaS) 제공 |
| **② 대타 SOS** | `/daeta` | **긴급 대타 호출 및 매칭**<br>- 대타 SOS 요청서 작성<br>- 내 주변 대타 대기 알바생 카드 핏 (스와이프 매칭 피드) | **긴급 땜빵 일거리 찾기**<br>- 즉시 출근 가능 대기 스위치 (`On/Off`) | **거래(Transaction)**<br>로컬 노동력의 초단기 긴급 실시간 공유 |
| **③ 탐색** | `/explore` | **상시 인재 매칭**<br>- 신창면 일대 알바생 프로필 나열<br>- 성향 궁합 지수 확인 및 러브콜 제안 | **상시 구인공고 탐색**<br>- 내 위치 주변 일반 구인공고 리스트<br>- 성향 궁합이 잘 맞는 매장 매칭 지원 | **유입(Acquisition)**<br>신규 일자리 및 신규 인력 탐색 |
| **④ 채팅** | `/chat` | **1:1 대화 & 계약 협의**<br>- 매칭된 알바생과 1:1 대화<br>- AI 매니저 PAZ와의 대화 내용 통합<br>- 표준근로계약서 체결 인터페이스 | **1:1 대화 & 명세 확인**<br>- 매칭된 사장님과 협의<br>- 전자계약서 작성 및 서명 | **보증(Conversion)**<br>정식 고용 전 신뢰 관계 구축 및 행정 처리 |
| **⑤ 성향/MY** | `/mypage` | **매장 및 계정 설정**<br>- 매장 프로필 수정<br>- 사장님 HEXACO 분석 결과 다시 보기<br>- 계좌 실명인증 상태 관리 | **내 프로필 및 성향**<br>- 알바생 HEXACO 분석 결과 및 배지 현황<br>- 내 구직 이력 및 신뢰도 점수 조회 | **설정(Setup)**<br>성향 테스트 재응시 및 개인 정보 변경 |

## 3. 추천 사용자 시나리오 흐름 (User Flow)

이 5대 탭 구조를 통해 가입 허들을 낮춘 후의 전체 흐름이 자연스럽게 흐릅니다.

### 3.1 사장님 (Employer) 시나리오
1. **가입 & 매장 등록**: 3필드 온보딩 후 `/myteam` 탭에서 매장 정보를 최초 등록합니다.
2. **기존 알바 영입**: `/myteam` 내의 `[직원 초대 코드 생성]`을 통해 카카오톡으로 기존 알바생에게 초대 링크를 보냅니다.
3. **근태 및 명세 자동화 (SaaS)**: 알바생이 링크를 타고 가입하면 자동으로 `/myteam` 직원 명부에 편입되며, 매일 출퇴근 체크 및 급여 정산이 자동으로 굴러갑니다.
4. **긴급 구인 (대타 SOS)**: 갑작스럽게 땜빵이 필요할 때, `/daeta` 탭으로 가서 즉시 SOS를 날려 신창면 주변의 즉시 대기 상태인 알바생들을 매칭받습니다.

### 3.2 알바생 (Worker) 시나리오
1. **초대 수락 및 가입**: 사장님의 카톡 초대 링크를 클릭, 1초 카카오 가입 후 즉시 검증된 `Tier1` 알바생으로 등록됩니다.
2. **근태 체크 및 급여 관리**: 매장 출근 후 `/myteam`에서 GPS 1탭 체크인을 누릅니다. 말일이 되면 월말 정산 명세서(PDF)를 다운로드합니다.
3. **부수입 창출 (대타)**: 비는 시간에 `/daeta` 탭에서 **`[즉시 대기 On]`** 상태로 켜둡니다. 주변 매장에서 대타 요청 푸시가 오면 즉시 수락하여 일당을 벌어갑니다.

## 4. 단계별 구현 가이드 (BottomNav.tsx 개편안)

위 내비게이션 바는 `components/BottomNav.tsx`에서 즉각 개편할 수 있습니다.

### 4.1 탭 변경 설정 적용안 (코드 수정 가이드)
현재 4개로 고정되어 있는 `tabs` 배열을 아래와 같이 **5개**로 확장하여 UI를 갱신합니다.
```typescript
const tabs = [
  { 
    icon: "ti-calendar-event", // 근태 전용 달력/이벤트 아이콘
    label: "근태/관리", 
    path: "/myteam", 
    active: pathname.startsWith("/myteam") 
  },
  { 
    icon: "ti-bolt", // 대타 전용 번개/볼트 아이콘
    label: "대타 SOS", 
    path: "/daeta", 
    active: pathname.startsWith("/daeta") 
  },
  { 
    icon: "ti-compass", 
    label: "탐색", 
    path: "/explore", 
    active: pathname.startsWith("/explore") || pathname.startsWith("/job") || pathname.startsWith("/worker/") 
  },
  { 
    icon: "ti-message-2", 
    label: "채팅", 
    path: "/chat", 
    active: pathname.startsWith("/chat") && !pathname.includes("/paz"), // AI 매니저 PAZ는 플로팅 버튼으로 분리
    badge: unreadCount 
  },
  { 
    icon: "ti-user-circle", 
    label: "성향/MY", 
    path: "/mypage", 
    active: pathname.startsWith("/mypage") || pathname.startsWith("/personality") || pathname.startsWith("/result") || pathname.startsWith("/profile") 
  },
];
```

### 4.2 추가 예외 처리 수정 (`isHiddenPath`)
* `/daeta` 경로는 사용자가 즉시 접근해야 하므로, 내비바가 숨겨지는 경로 목록(`isHiddenPath`)에서 제거하여 하단 내비바가 항상 노출되도록 제어합니다.
```typescript
// 변경 전
const isHiddenPath = ["/login", "/signup", "/auth", "/", "/chat/", "/paz", "/sudoku", "/daeta"].some(...);

// 변경 후
const isHiddenPath = ["/login", "/signup", "/auth", "/", "/chat/", "/paz", "/sudoku"].some(...);
```

이 구조는 파잡 v2가 단순한 "구인 구직 매칭 게시판"을 넘어 사장님들의 일상적 워크플로우에 깊숙이 관여하는 **진정한 HR & 긴급 대타 공유 플랫폼**으로 발돋움하는 지름길입니다.
구조 개편 진행 여부에 대해 검토해 보시고 피드백을 주시면 바로 적용 작업을 시작하도록 하겠습니다!
