## ① 계약서 템플릿화 ★★★

**문제:** 매번 20개+ 항목 처음부터 입력, 같은 매장 두 번째 직원도 동일 반복  
**개선:**
- 같은 매장의 기존 계약서 불러와 "복사 후 이름/날짜만 바꾸기" 기능
- 매장 등록 시 기본 근무조건(시급·요일·시간) 저장 → 계약서 자동채움 소스로 활용
- `/contract` 진입 시 "이전 계약서 불러오기" 선택지 제공

**관련 파일:** `app/contract/page.tsx`, `app/employer/register/page.tsx`

## ② 사장님 첫 진입 온보딩 가이드 ★★★

**문제:** 가입 후 `/myteam` 진입 시 빈 화면, 다음 행동 불명확  
**개선:**
- 매장 미등록 상태일 때 빈 화면 대신 "3단계 시작 가이드" 표시
  1. 매장 등록하기
  2. 직원 초대 or 공고 올리기
  3. 근로계약서 작성
- 각 단계 완료 시 체크 표시 및 다음 단계 CTA

**관련 파일:** `app/myteam/page.tsx`, `app/onboarding/page.tsx`

---

## ③ 급여 자동발행 설정 ★★☆

**문제:** 매월 사장님이 직접 팀원 상세 → 급여탭 → 발행 수동 진행  
**개선:**
- 팀원별 "매월 N일 자동발행" 토글 설정
- 설정 시 크론(`/api/cron/payslip`)이 해당 일자에 자동 계산·발행·알림 전송
- 알바생에게 급여명세서 알림 자동 발송

**관련 파일:** `app/employer/team/[id]/page.tsx`, `app/payslip/page.tsx`, `app/api/cron/`

---

## ④ 채용 확정 후 넥스트 스텝 배너 ★★☆

**문제:** "채용됐어요 🎉" 이후 계약서 작성 버튼이 시스템 메시지 안에만 있어 사장님이 놓침  
**개선:**
- 채용 확정(hired) + 계약서 미작성 상태일 때 채팅방 상단에 고정 배너 표시
  - "📄 근로계약서를 작성해주세요 → [작성하기]"
- 계약서 작성 완료 시 배너 자동 사라짐

**관련 파일:** `app/chat/[id]/page.tsx`

---

## ⑤ 매장 등록 2단계 분리 ★☆☆

**문제:** 매장 기본정보 + 공고 + 근무조건이 한 페이지에 혼재, 이탈률 높음  
**개선:**
- Step 1: 매장 기본정보 (이름·업종·주소·사진) — 1회 등록 후 재사용
- Step 2: 공고 내용 (직종·시급·근무요일·시간·모집인원) — 공고별로 등록
- 매장 정보는 한 번 등록하면 다음 공고 시 자동채움

**관련 파일:** `app/employer/register/page.tsx`

---

## ⑥ 근태 관리 UX 정리 ★☆☆

**문제:** 사장님의 출퇴근 수정 UI가 깊이 숨어 있음, 지각·결근 알림 흐름 불명확  
**개선:**
- 팀원 근태 탭에서 날짜별 출퇴근 시간 인라인 수정 가능하게
- 지각·결근 발생 시 사장님에게 push 알림 (현재 크론 있으나 알림 연결 확인 필요)
- 매장 GPS 좌표 미등록 시 근태 탭 진입 전 경고 안내

**관련 파일:** `app/employer/team/[id]/page.tsx`, `app/api/cron/checkin/route.ts`
